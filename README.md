# Shopping Support — UX Prototype v0.8

家庭内の **未開封予備在庫・買い物リスト・単価比較** を少ない操作でつなぐ、モバイル向けUXレビュー用の試作品です。

> **重要：これはサンプルデータを使った設計レビュー版です。実生活での本番利用や個人情報の保管に使用しないでください。**

## 2026-11-04 アプリアイコンの設定

ユーザーが選んだ**深緑の箱＋チェック記号のロゴ**をiPhoneのホーム画面用アイコンに採用。原画像の形状と配色をもとにアイコンサイズへ整えたものです。

- iPhone（Safariのホーム画面追加）：`assets/apple-touch-icon.png`（180px）
- Android／Webアプリのマニフェスト：`assets/icon-192.png`／`assets/icon-512.png`
- ブラウザタブ：`assets/favicon-32.png`
- GitHub Pagesのサブパスでも動く相対パスを使用。
- **iPhoneでの確認方法**：Safariで公開URLを開き、共有メニュー→「ホーム画面に追加」。既に同じサイトをホーム画面に追加してある場合、アイコンがキャッシュされることがあるため、**古いホーム画面ショートカットを削除して再追加**する。ブラウザ内の保存データを消す操作はしない。
- ここではアイコンとマニフェストを設定したのみ。**オフラインPWA、正式データ移行、本番利用の保証は未実装**。
- 元の利用者提供画像は作業元として保持し、リポジトリの各PNGはロゴ輪郭を忠実に抽出した、ホーム画面向けの軽量な再構成版。

## 2026-11-07 UX v0.8｜在庫分類と購入入力の補助

- **分類は最大5件、未分類は別枠**。初期は「日用品／キッチン用品／食品・調味料」。設定画面で追加・名称変更・削除。商品登録・編集時に分類を選択できる。
- 在庫一覧は分類別の開閉式。商品がない分類のセクションは非表示。並び替えは分類内で実施する。
- 管理商品名を入力すると、**内蔵キーワード辞書とユーザーが過去に修正した同名商品の分類**から候補を表示。AI利用や外部通信はなし。判定が曖昧なら未分類、分類選択は任意。
- 分類は**名前ではなく固定IDで管理**し、分類名を変更しても関連商品はそのまま。分類削除時は移動先を他の分類または未分類から指定し、登録商品・購入履歴を削除しない。
- 購入の任意情報に**最近使った店舗（全商品共通）**と**具体商品名（同じ管理商品の購入履歴）**の選択候補を追加。候補を押しても購入は確定せず、購入ボタンで従来どおり処理する。
- 既存のデモJSON識別子（UX-DEMO-0.3）とlocalStorageキーは変更せず、旧データは不足する分類情報を読込時に補完。既存の在庫・履歴・購入支援3機能・テーマ・アプリアイコンは維持。
- テスト：tests/inventory-categories.test.mjsを新設。既存試験と合わせて模擬実行24ケースを確認。**GitHub Pagesの最新版配信・iPhone Safari実機の画面と旧バックアップの復元は未確認**。

## 2026-11-07 UX v0.7｜買い物支援ツール

- 下部タブ「単価比較」を「**買い物支援**」に変更。入口画面から「単価比較」「割引計算」「100g比較」を選択。各ツール画面上部にも3機能の切替リンクを設置。
- **単価比較**：通常は税込価格と数量のみ。セット商品だけ「セット商品を比較」を押してセット数を任意入力。空欄は1として計算し、合計数量=1つあたり数量×セット数を使用。例：200組×4箱1,000円と300組×3箱1,000円なら、後者が1組あたり約11.1%割安。
- **割引計算**：税込価格と割引率(%)を入力して支払額・値引き額を表示。0〜100%に対応。円単位に四捨五入。
- **100g比較**：税込価格と内容量(g)の入力で100gあたりの価格を比較。表示単位はg固定で選択欄なし。
- 計算機能の入力値は画面切替時に空欄へ。購入履歴には計算だけで記録されず、比較画面から明示的に購入を選んだ場合だけ価格を渡す。
- **将来候補（未実装）**：税抜税込換算、クーポン・ポイント、まとめ買い特典、予算の合算など。
- 保存済み在庫／購入履歴／並び順／テーマ／アイコン設定および`UX-DEMO-0.3`デモJSON形式は維持。
- 回帰テスト：`node --test tests/*.test.mjs`（新規`tests/shopping-tools.test.mjs`を追加）。GitHub上コードの構文・模擬操作は検証したが、iPhone実画面と最新Pages配信は未確認。

## 2026-11-03 UX v0.5の改善

- iPhoneの入力時に画面が拡大しないよう、全入力欄を16px以上に統一。ズームそのものは禁止していません。

## 画面と動作

- **買い物**：在庫不足を自動表示。1本だけ購入しても目標在庫に達するまで表示し続けます。買い物メモは在庫と独立。
- **在庫**：未開封の予備だけを数え、開封したら `−1`。商品分類（最大5＋未分類）で一覧を折りたたみ表示。
- **買い物支援**：通常／セット商品の単価比較、割引計算、100g比較を提供。数量の単位は自動換算しません。
- **履歴**：購入・開封・調整の操作を自動記録。種類別タブ、10件ずつのページ送り、折りたたみに対応。
- **設定**：分類の追加・名称変更・削除、スタイリッシュ／ダークブルーのテーマ切替、デモのJSON出力・復元・リセット。

## 開く

GitHub Pagesの公開設定が完了すると、次のURLで表示される予定です。

**https://pon-user.github.io/Shopping_Support/**

GitHub Pages の設定がまだの場合：

1. リポジトリの **Settings → Pages** を開く。
2. **Build and deployment → Source** を **Deploy from a branch** にする。
3. **Branch** を `main`、フォルダを `/(root)` にして **Save**。
4. **Actions** や **Settings → Pages** で配信が成功していることを確認し、URLを開く。

`index.html` のみで実行でき、ビルドは不要です。

## データの扱いと制約

- 初期データは架空のサンプルです。ブラウザー内の `localStorage` に、**試作品の状態だけ**を保存します。
- デモのJSON形式 `UX-DEMO-0.3` はv0.8でも維持しますが、**本番用のJSONスキーマではありません**。将来の正式版に引き継げる保証はありません。
- **IndexedDB、PWA、クラウド同期、外部価格取得、厳密なイベントのトランザクション保証、正式バックアップは未実装**です。
- この試作品に外部APIによる在庫・購入履歴の送信機能はありません。ただしブラウザーの保存データは失われることがあります。
- iPhone Safariでの最終実機テストとアクセシビリティ確認は、公開後のレビュー工程です。
