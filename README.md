# Shopping Support — UX Prototype v0.6

家庭内の **未開封予備在庫・買い物リスト・単価比較** を少ない操作でつなぐ、モバイル向けUXレビュー用の試作品です。

> **重要：これはサンプルデータを使った設計レビュー版です。実生活での本番利用や個人情報の保管に使用しないでください。**

## 2026-11-04 アプリアイコンの設定

ユーザーが選んだ**深緑の箱＋チェック記号のロゴ**をiPhoneのホーム画面用アイコンに採用。原画像の形状と配色をもとにアイコンサイズへ整えたものです。

- iPhone（Safariのホーム画面追加）：`assets/apple-touch-icon.png`（180px）
- Android／Webアプリのマニフェスト：`assets/icon-192.png`／`assets/icon-512.png`
- ブラウザタブ：`assets/favicon-32.png`
- GitHub Pagesのサブパスでも動く相対パスを使用。
- **iPhoneでの確認方法**：Safariで公開URLを開き、共有メニュー→「ホーム画面に追加」。既に同じサイトをホーム画面に追加してある場合、アイコンがキャッシュされることがあるため、**古いホーム画面ショートカットを削除して再追加**する。ブラウザ内の保存データを消す操作はしない。
- ここではアイコンとマニフェストを設定したのみ。**オフラインPWA、正式データ移行、本番利用の保証は未実装**。
- 元の利用者提供画像は作業元として保持し、リポジトリの各PNGはロゴ輪郭を忠実に抽出した、ホーム画面向けの軽量な再構成版。

## 2026-11-03 UX v0.6の改善

- **履歴**：「すべて／購入／開封／調整・取消」の4種類から切替。新しい順に最大10件、ページ送りで過去の履歴も閲覧できます。全体と各履歴を折りたためます。
- **テーマ**：「スタイリッシュ／ダークブルー」の2種類。従来の「可愛い」設定は初回表示時にスタイリッシュへ自動移行し、在庫・履歴データは維持されます。
- 表示件数を減らしても、保存されている履歴は削除しません。従来のJSON形式（`UX-DEMO-0.3`）は維持します。
- テスト：`node --test tests/*.test.mjs`（ソース側にテストを追加）。iPhone実機でのレイアウトと配信反映は別途確認対象。

## 2026-11-03 UX v0.5の改善

- iPhoneの入力時に画面が拡大しないよう、全入力欄を16px以上に統一。ズームそのものは禁止していません。
- 新規商品・単価比較の数値は空欄で開始。新規在庫を未入力で登録する場合、在庫0、補充ライン1、補充目標2として保存。
- 比較は「価格÷数量」。単位選択は不要ですが、**比較する数量は同じ単位で入力**してください。
- 入力中は「次へ」で次欄へ。必要時は比較入力を「クリア」できます。
- ユーザー向けの「予備」は「在庫」に揃え、説明は簡潔に変更。
- テスト用：`node --test tests/stock-state-css.test.mjs tests/ux-input-flow.test.mjs`。

## 2026-11-02 UX v0.4.2の修正

- 予備なしだけ枠・余白が異なる原因はCSSクラスの競合でした。空画面用の`.empty`を状態記号から外し、`is-zero`に変更。
- 空画面の表示は従来どおり。商品カードの形は全状態で統一し、補充状態は左端の色だけで区別します。
- 回帰テスト：`node --test tests/stock-state-css.test.mjs`。iPhoneの実表示は再レビュー対象です。

## 2026-11-02 UX v0.4.1の調整

- 予備なしのカードも他の商品と**同じ背景・枠・余白**に揃え、在庫ゼロは左の状態ラインを**赤色**にするだけで識別します。操作・デモデータの保存方式は変更していません。

## 2026-11-02 UX v0.4の主な改善

- 在庫一覧をコンパクトにし、商品絵文字を状態ラインへ置き換えました（補充目安＝アンバー／在庫ゼロ＝赤）。
- 在庫一覧の「並び替え」モードで、ドラッグまたは上下ボタンで順番を変えられます。並びは保存されます。
- 完了通知は自動で消えます。取り消し可能な通知は約6秒、それ以外は約2.3秒。
- iPhoneのステータスバー・ホームインジケーター・狭い画面に合わせた余白を調整しました。
- 旧v0.3デモの保存データとJSON形式を引き続き利用できます。
- 技術的なテスト結果・残る確認は [変更履歴](./CHANGELOG.md) を参照してください。

## 画面と動作

- **買い物**：在庫不足を自動表示。1本だけ購入しても目標在庫に達するまで表示し続けます。買い物メモは在庫と独立。
- **在庫**：未開封の予備だけを数え、開封したら `−1`。数量は手入力で修正可能。
- **単価比較**：価格と数量の数字だけで比較。数量の単位は自動換算しません。
- **履歴**：購入・開封・調整の操作を自動記録。種類別タブ、10件ずつのページ送り、折りたたみに対応。
- **設定**：スタイリッシュ／ダークブルーのテーマ切替、デモのJSON出力・復元・リセット。

## 開く

GitHub Pagesの公開設定が完了すると、次のURLで表示される予定です。

**https://pon-user.github.io/Shopping_Support/**

GitHub Pages の設定がまだの場合：

1. リポジトリの **Settings → Pages** を開く。
2. **Build and deployment → Source** を **Deploy from a branch** にする。
3. **Branch** を `main`、フォルダを `/(root)` にして **Save**。
4. **Actions** や **Settings → Pages** で配信が成功していることを確認し、URLを開く。

`index.html` のみで実行でき、ビルドは不要です。

## データの扱いと制約

- 初期データは架空のサンプルです。ブラウザー内の `localStorage` に、**試作品の状態だけ**を保存します。
- デモのJSON形式 `UX-DEMO-0.3` はv0.6でも維持しますが、**本番用のJSONスキーマではありません**。将来の正式版に引き継げる保証はありません。
- **IndexedDB、PWA、クラウド同期、外部価格取得、厳密なイベントのトランザクション保証、正式バックアップは未実装**です。
- この試作品に外部APIによる在庫・購入履歴の送信機能はありません。ただしブラウザーの保存データは失われることがあります。
- iPhone Safariでの最終実機テストとアクセシビリティ確認は、公開後のレビュー工程です。
